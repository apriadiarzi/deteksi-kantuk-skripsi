# Catatan versi (penting untuk deploy di Streamlit Cloud):
# - av 14.x tidak punya wheel siap pakai di PyPI, jadi pip mencoba compile
#   dari source dan gagal (butuh ffmpeg 7 + compiler).
# - aiortc dipin ke 1.9.0 (bukan 1.10.1) — versi lebih baru terbukti gagal
#   nyambung ICE lewat internet sungguhan (STUN-only) di Streamlit Cloud,
#   walau kode & konfigurasinya identik dan lolos tes di localhost. Repo
#   referensi tutorial (veb-101/Drowsiness-Detection-Using-Mediapipe-Streamlit,
#   terbukti jalan di Streamlit Cloud pakai rtc_configuration STUN-only yang
#   sama) memakai aiortc versi ~2024, jauh lebih dekat ke 1.9 daripada 1.10+.
#   1.9.0 adalah versi terlama yang masih bisa dipasang cloud (butuh av<13,
#   dan av<13 baru tersedia wheel-nya mulai 12.x — av<12 harus compile dari
#   source dan gagal).
# - aiortc 1.9.0 butuh cryptography>=42.0.0 dan pyOpenSSL>=24.0.0, sehingga
#   pin lama cryptography==38.0.0 dilepas.
# - mediapipe >= 0.10.13 butuh protobuf >= 4.25.3, bentrok dengan
#   streamlit 1.17.0 yang butuh protobuf < 4.
cryptography
pyOpenSSL
aiortc==1.9.0
av==12.3.0
# mediapipe 0.10.x dikompilasi untuk numpy 1.x dan opencv 4.x; kalau pip bebas
# memilih, dia ambil numpy 2.x / opencv 5.x dan mediapipe gagal saat import.
numpy<2
opencv-contrib-python<5
pydub
mediapipe==0.10.11
streamlit==1.17.0
streamlit_webrtc==0.43.4
streamlit-nested-layout==0.1.1
streamlit-autorefresh
altair==4.0
requests
python-decouple
# Driver Postgres (Neon). Filesystem Streamlit Community Cloud itu ephemeral —
# container dibangun ulang dari repo tiap redeploy, jadi SQLite lokal selalu
# ter-reset dan akun yang didaftarkan lewat web hilang. Datanya dipindah ke
# database eksternal yang hidup di luar container.
psycopg2-binary
